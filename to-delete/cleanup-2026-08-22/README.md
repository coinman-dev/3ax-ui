## Подробности

**Source maps.** `web/assets` встраивается в бинарник целиком (`//go:embed assets`),
так что 4.4 МБ карт лежали в каждом релизе. Браузер запрашивает их только при
открытых DevTools — теперь на этот запрос будет 404, на работу панели это не
влияет. Размер бинарника: 84 МБ → 80 МБ.

**Win64OpenSSL_Light-3_6_0.exe.** Файл ни на что не ссылается по имени; в релиз
он попадал только потому, что `.github/workflows/release.yml` копирует
`..\windows_files\*` целиком. После переноса шаг копирования продолжает работать
(копируется `readme.txt`), а в сам `readme.txt` добавлена ссылка на официальную
страницу загрузки OpenSSL — инструкция для пользователей Windows не потерялась.

**FUNDING.yml.** Кнопка «Sponsor» на GitHub вела на аккаунты автора upstream-проекта.
Если она нужна — верните файл и замените имена на свои.
